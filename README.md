## 🌟 Key Features

1. **Student Portal**
   - Candidate admission, course progress, timetable, and study materials.
   - Dynamic online fee payment with official **Google Pay & BHIM UPI QR Code** (`9907323533-1@okbizaxis`).
   - Automated verified Certificate download with verifiable QR code.
   - Geo-tagged attendance check-in.

2. **Partner / Franchise Training Center Portal**
   - Franchise administration, student enrollment, and batch scheduling.
   - Course material distribution and center fee remittance.
   - Instant student marksheet and certificate issuance.

3. **Super Admin & Controller Console**
   - 1-Click Director authentication (**Soumen Ghosh** & **Subrata Roy**).
   - Course management, franchise approvals, certificate verification ledger, and live analytics.

4. **Public Verification & Showcase**
   - Instant Certificate & Marksheet verification by Certificate ID / Registration Number.
   - Official foundation legal charter, accreditation details, and contacts.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone or extract the repository
cd jsss-foundation-academy

# Install dependencies
npm install
```

### Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### Production Build
```bash
npm run build
npm run preview
```
